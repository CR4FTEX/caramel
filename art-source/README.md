# Art source files

Editable source files for Caramel's art go here: Blockbench projects (`.bbmodel`), Aseprite files and layered images, so the art can be adjusted later.

This folder is outside `src/`, so nothing in it ships in the mod jar. Exported textures, block and item models, and sounds go under `src/main/resources/assets/caramel/`. Entity models become Java code in `src/client/java/io/github/cr4ftex/caramel/client/model/`. See [docs/TEXTURES.md](../docs/TEXTURES.md).
